# confession-matrix

Confession Matrix v9.5 — pygame particle animation: Lorenz butterfly → beating heart → particle text

## What it is

A 10,000-particle pygame animation that opens on a Lorenz-attractor butterfly, morphs into a 3D heart whose heartbeat accelerates, then explodes into particle text cycling through `hey` / `hello` / `hi` / `bye`.

## Run it

```bash
pip install pygame
python confession_matrix.py
```

## Controls

- `Tab` — Switches the color palette and, once the text has formed, the text.
- `Space` — Advances the flow.
- `1` — Resets.
